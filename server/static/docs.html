API для разработчиков

1. Как это работает

II Proxy принимает ваши запросы на наш сервер, списывает стоимость с баланса вашего аккаунта и обрабатывает их через OpenAI-совместимый API (формат Chat Completions). Для вызовов нужен один ключ II Proxy (см. ниже) и slug модели из нашего каталога (например, openai/gpt-4o).

Список доступных slug и тарифов смотрите в разделе «Тарифы» или через GET /api/models.

5. Озвучка ответа (опционально)

        

          К тому же POST …/api/v1/messages можно добавить поле ttsVoice — голос для
          синтеза речи в потоке, если используется модель с поддержкой голосового сценария (как в чате на сайте).
          Неизвестное значение заменяется на голос по умолчанию (alloy).
        

        

          Допустимые значения: alloy, echo, fable, onyx,
          nova, shimmer.
        

        
{
  "modelSlug": "…",
  "stream": true,
  "ttsVoice": "nova",
  "messages": [ … ]
}

      


      

        
6. Генерация изображений

        

          Отдельного URL для «картинок» нет: используется тот же POST …/api/v1/messages.
          В modelSlug выберите модель с генерацией изображений — в
          «Тарифах» или в ответе GET /api/models смотрите
          supportsImageGeneration (или вкладку карточки модели на сайте).
        

        

          Для таких моделей прокси добавляет к запросу провайдеру режим
          modalities: ["image", "text"], как во встроенном чате. Промпт — обычное сообщение
          user в messages (при необходимости можно комбинировать с vision-вводом по
          правилам выбранной модели).
        

        

          При "stream": true ответ — SSE в формате chat completions; ссылки на сгенерированные
          изображения приходят в потоке чанков. При "stream": false — один JSON ответа провайдера
          (OpenAI-совместимая схема для данной модели).
        

        

          Пример: в теле ниже подставляется первый slug с supportsImageGeneration из ответа
          GET /api/models (если запрос удался), иначе — значение по умолчанию из каталога.
