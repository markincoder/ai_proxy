Старые диалоги

Удаляются сохранённые чаты без активности дольше выбранного срока (по времени последнего изменения в БД, UTC). Операция необратима; текущие открытые у пользователей диалоги на сервере не отслеживаются — при следующей синхронизации исчезнут из истории.

Обращения пользователей: новые сообщения подсвечиваются по счётчику, ответы — внизу.

Обращение

Сообщение показывается всем посетителям вверху сайта (техработы, предупреждения). Снимите флажок «Показывать», чтобы скрыть.

Новости на /news — от новых к старым. Картинка: файл (до 5 МБ, JPEG/PNG/GIF/WebP) или необязательная внешняя ссылка; загруженные файлы хранятся в каталоге на сервере (NEWS_UPLOAD_DIR).
