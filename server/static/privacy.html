Политика конфиденциальности

действует с 12.05.2026

Настоящая Политика описывает, как сервис II Proxy (далее — «Сервис», «мы», «Оператор») подходит к обработке информации при использовании веб‑интерфейса и связанных функций. Политика дополняет пользовательское соглашение и применима совместно с ним.

1. Общие положения

1.1. Оператор стремится ограничить объём собираемых данных минимально необходимым для работы Сервиса, учёта баланса и безопасности.

1.2. Действующая редакция Политики размещается по относительному пути /privacy. О существенных изменениях может сообщаться через интерфейс Сервиса или иными способами, если это предусмотрено законом.

2. Категории данных

2.1. На стороне Оператора хранится внутренний идентификатор учётной записи, технические данные сессии, сведения об операциях по балансу и содержимое диалогов/обращений в объёме, в котором вы их сохраняете в Сервисе. При регистрации по логину и паролю хранится выбранный логин и необратимый хэш пароля.

2.2. Оператор не сопоставляет на своей стороне указанные данные с ФИО, адресами электронной почты и номерами телефона пользователя как персональных данных конкретного гражданина. Авторизация через Яндекс ID, VK ID и оплата через ЮKassa выполняются у соответствующих операторов; обработка данных там регулируется их документами.

3. Передача третьим лицам и трансграничность

3.1. Для исполнения запросов к моделям искусственного интеллекта содержимое запросов и вложений может передаваться провайдерам API (в том числе OpenRouter) и может обрабатываться на серверах, расположенных за пределами Российской Федерации, при этом Оператор не хранит и не передает данных о Пользователе. Пользователь самостоятельно определяет, какие сведения включать в обращение к Сервису.

4. Обращения пользователя

Вопросы по Политике и запросы, связанные с обработкой информации, можно направить через страницу «Контакты» или иными способами, указанными на Сервисе.
