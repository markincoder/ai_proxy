    Чат с нейросетями

    Выбрана модель только распознавания речи (вкладка «Транскрипция»): запись с микрофона или аудиофайл попадает в чат как текст и оплачивается по тарифу. Для диалога с нейросетью переключитесь на модель из «Текст и чат» или другую диалоговую.

    У этой модели нет потока готового аудио в ответе API — только текст. Для музыки — Lyria 3 во вкладке «Музыка». Для озвучки ответа — GPT Audio во вкладке «Голос».

    Провайдер может отклонить и нейтральный запрос (политика контента, ложные срабатывания). Смените формулировку сцены или другую видео-модель.

    Пополнение баланса

    Платите только за использование

    Никаких подписок, месячных пакетов и абонементов — вы пополняете баланс и тратите его только на реальные запросы к моделям по тарифам в разделе «Все модели и тарифы».
